 বাজার দর | BazarDor
## Description

BazarDor is a Bengali web app that shows the daily prices of essential products such as rice, vegetables and fish. Users can compare prices across markets and see at a glance whether a price went up or down.

 Live Demo: (https://bazar-dor-indol-six.vercel.app/)

## Technologies Used
Next.js 16 (App Router) <br>
React <br>
Tailwind CSS <br>
daisyUI <br>
MongoDB <br>
Better Auth (Email/Password, Google, GitHub) <br>
Vercel (deployment) <br>
## Key Features
Daily Price Tracking: today's price with ▲ / ▼ change compared to yesterday. 
Market-wise Comparison: product details page with lowest, highest and average price across markets.<br>
Category Browsing: browse products by category. <br>
Authentication: sign up and sign in with email and password, Google or GitHub.<br>
Responsive Design: works smoothly on mobile, tablet and desktop.<br>

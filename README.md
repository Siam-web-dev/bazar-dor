 বাজার দর | BazarDor
## Description

BazarDor is a Bengali web app that shows the daily prices of essential products such as rice, vegetables and fish. Users can compare prices across markets and see at a glance whether a price went up or down.

 Live Demo: (https://bazar-dor-indol-six.vercel.app/)

## Technologies Used
Next.js 16 (App Router)
React
Tailwind CSS
daisyUI
MongoDB
Better Auth (Email/Password, Google, GitHub)
Vercel (deployment)
## Key Features
Daily Price Tracking: today's price with ▲ / ▼ change compared to yesterday.
Market-wise Comparison: product details page with lowest, highest and average price across markets.
Category Browsing: browse products by category.
Authentication: sign up and sign in with email and password, Google or GitHub.
Responsive Design: works smoothly on mobile, tablet and desktop.
